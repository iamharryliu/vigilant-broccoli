Backlog grouped by category. Each section is a markdown table (`ID | Priority | Agent | Effort | Brief | Description | Recommended Fix`), ordered by priority. Priority values: **P1** (highest) → **P2** → **P3**, then **NA** (nice-to-have or deliberately-accepted risk). Agent: **auto** (an agent can finish and verify it in a PR), **assisted** (an agent writes the change; a person applies, rotates or deploys it), **human** (needs console, hardware or account access). Effort: **S**, **M**, **L**. Brief: the Description and Recommended Fix summarized in a few sentences. IDs are stable 6-hex handles; `pnpm agentic-pr-create <id>` resolves an item from its row.
