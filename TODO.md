# Repo Audit — Outstanding Issues

One table, one row per issue, grouped by Type and ordered by Priority within each Type; the dev-dashboard TODO view builds its sections, table of contents and sorting from these columns. Type: **QA** (manual checks of what agentic solves shipped to apps, libs, infrastructure services, workflows or dotfiles, one row per project with links to the PRs being checked; delete the row once checked), **Security**, **Performance**, **Maintenance**, **Chore**, **Refactor**, **Feature Enhancements**, **UI Cleanup**, **Not so serious**. Priority: **P1** (highest) → **P2** → **P3**, then **NA** (nice-to-have or deliberately-accepted risk). Agent: **auto** (an agent can finish and verify it in a PR), **assisted** (an agent writes the change; a person applies, rotates or deploys it), **human** (needs console, hardware or account access). Effort: **S**, **M**, **L**. Model: the Claude model to dispatch with, **haiku** (mechanical edit copying an existing pattern), **sonnet** (default), **opus** (security-sensitive design, subtle correctness, or cross-service L work), **NA** for human rows. Brief: the Description and Recommended Fix summarized in a few sentences. IDs are stable 6-hex handles; `pnpm agentic-pr-create <id>` resolves an item from its row. See [todo-pattern.md](./docs/todo-pattern.md) for the format.
