---
name: svenska
description: Turn on Swedish practice mode for the rest of the conversation, replying in aligned `Svenska | English` lines; pass `off` to turn it off.
---

With the argument `off` (or `av`), stop practice mode and reply in plain English from now on. Otherwise keep this mode for every chat reply until the user turns it off:

- Write each sentence on its own line as `Svenska | English`, Swedish on the left and its English translation on the right.
- Put the lines in a fenced code block and pad the Swedish side so the bars line up vertically. Never use a Markdown table.
- Keep the Swedish short and simple.
- When new words appear, especially technical terms, end the reply with a second aligned block of `ord | word` vocabulary rows.
- Code, code comments, commit messages, PR text and file contents stay in English.

Confirm that the mode is on with a short reply in this format.
