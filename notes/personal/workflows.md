## Update Email Signature

1. Edit the signature HTML source: update the changed field (for example the phone number in both the displayed text and the `tel:` link).
2. Apply the same change to the hosted copy of the signature page and to the resume's contact block so they stay consistent.
3. Deploy the site so the hosted signature page serves the new version, then open it to confirm.
4. Paste the rendered signature into the mail client's signature settings, replacing the old one.
5. Send a test email to check the layout, images and links.
