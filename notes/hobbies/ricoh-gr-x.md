## Mode Dial

| Mode | Name | Meaning |
| --- | --- | --- |
| AUTO | Auto | Camera chooses aperture, shutter speed and ISO |
| Av | Aperture priority | You set the aperture; the camera picks the shutter speed |
| B | Bulb | Shutter stays open while the shutter button is held; for long exposures |
| M | Manual | You set aperture, shutter speed and ISO |
| P | Program | Camera sets aperture and shutter speed; you can shift the combination |
| T | Time | Shutter opens on the first press and closes on the second; for long exposures |
| Tv | Shutter priority | You set the shutter speed; the camera picks the aperture |
| U1 | User setting 1 | Recalls a saved custom set of shooting settings (mode, exposure, image control, etc.) |
| U2 | User setting 2 | Same as U1; a second saved set |
| U3 | User setting 3 | Same as U1; a third saved set |
