## Anatomy

### Deck

| Part      | Description                                                                        |
| --------- | ---------------------------------------------------------------------------------- |
| Concave   | The inward curve across the width of the deck that improves foot grip and control. |
| Deck      | The wooden board you stand on. Usually made from layered maple plywood.            |
| Grip Tape | Sandpaper-like adhesive surface applied to the top of the deck for traction.       |
| Kicktail  | The upward curve on the nose or tail that helps with tricks and control.           |
| Length    | Overall measurement from nose to tail.                                             |
| Nose      | The front end of the deck, usually slightly longer and steeper than the tail.      |
| Tail      | The back end of the deck used for popping tricks and steering.                     |
| Wheelbase | Distance between the inner mounting holes of the trucks.                           |
| Width     | Side-to-side measurement of the deck, typically in inches.                         |

### Trucks

| Part                | Description                                                                 |
| ------------------- | --------------------------------------------------------------------------- |
| Axle                | Metal rod running through the hanger that the wheels mount onto.            |
| Baseplate           | Flat part of the truck screwed into the deck.                               |
| Bushings            | Urethane rubber rings around the kingpin.                                   |
| Hanger              | Main horizontal part of the truck that the axle passes through.             |
| Hardware            | Bolts and nuts used to attach trucks to the deck.                           |
| Kingpin             | Large central bolt that holds truck components together.                    |
| Pivot Cup           | Small urethane cup that stabilizes truck movement at the pivot point.       |
| Risers / Riser Pads | Pads placed between trucks and deck to increase height.                     |
| Shock Pads          | Softer riser pads designed for vibration absorption.                        |
| Trucks              | Metal T-shaped assemblies mounted underneath the deck that hold the wheels. |

### Wheels

| Part            | Description                                                     |
| --------------- | --------------------------------------------------------------- |
| Bearing Shields | Covers protecting bearings from dirt and debris.                |
| Bearings        | Precision metal rings inside wheels that allow smooth spinning. |
| Durometer       | Wheel hardness rating, usually measured on the “A” scale.       |
| Spacer          | Small tube placed between bearings inside a wheel.              |
| Speed Rings     | Small washers placed between bearings and axle nuts.            |
| Wheel Diameter  | Height of the wheel in millimeters.                             |
| Wheels          | Urethane rollers attached to the trucks.                        |

## Board Types

| Term             | Description                                                              |
| ---------------- | ------------------------------------------------------------------------ |
| Complete         | A fully assembled skateboard.                                            |
| Cruiser          | Skateboard designed mainly for transportation and comfort.               |
| Longboard        | Longer skateboard designed for cruising or downhill riding.              |
| Old School Shape | Wider, less symmetrical skateboard deck shape common in earlier designs. |
| Penny Board      | Small plastic cruiser skateboard.                                        |
| Popsicle Deck    | Standard symmetrical skateboard deck shape.                              |
| Setup            | A skateboard’s overall component configuration.                          |

## Tricks

### Stance and Direction

| Term      | Description                                                            |
| --------- | ---------------------------------------------------------------------- |
| Backside  | The skater's back faces the obstacle through the trick or turn.        |
| Fakie     | Rolling backwards with the feet still in their normal stance.          |
| Frontside | The skater's chest faces the obstacle through the trick or turn.       |
| Goofy     | Riding with the right foot forward.                                    |
| Mongo     | Pushing with the front foot instead of the back foot.                  |
| Nollie    | Popping off the nose while rolling forward in normal stance.           |
| Regular   | Riding with the left foot forward.                                     |
| Switch    | Riding with the opposite foot forward, as if the stance were mirrored. |

### Trick Basics

| Term      | Description                                                                  |
| --------- | ---------------------------------------------------------------------------- |
| Air       | Leaving the ramp above the coping, usually with a grab.                      |
| Bail      | Stepping off on purpose when a trick is not going to land.                   |
| Grab      | Holding the board with a hand in the air.                                    |
| Manual    | Rolling on the back wheels only; a nose manual balances on the front wheels. |
| No-Comply | The front foot steps to the ground while the back foot pops the board.       |
| Ollie     | Popping the tail and dragging the front foot up to jump with the board.      |
| Pop       | Snapping the tail against the ground to lift the board.                      |
| Primo     | Landing or balancing on the board's side rather than its wheels.             |
| Slam      | Falling hard, as opposed to a controlled bail.                               |

### Grinds and Slides

| Term              | Description                                                                  |
| ----------------- | ---------------------------------------------------------------------------- |
| 5-0               | Grinding on the back truck only, nose in the air.                            |
| 50-50             | Grinding on both trucks, board parallel to the obstacle.                     |
| Boardslide        | Sliding on the middle of the deck, front wheels crossing the obstacle first. |
| Crooked (K-Grind) | Front truck grind with the nose angled into the obstacle.                    |
| Darkslide         | Sliding upside down with the griptape on the obstacle.                       |
| Feeble            | Back truck grind with the nose hanging over the far side.                    |
| Lipslide          | Boardslide entered with the back wheels crossing the obstacle first.         |
| Nosegrind         | Grinding on the front truck only, tail in the air.                           |
| Noseslide         | Sliding on the nose with the board across the obstacle.                      |
| Smith             | Back truck grind with the nose dipped below the obstacle.                    |
| Tailslide         | Sliding on the tail with the board across the obstacle.                      |

### Lip Tricks

| Term          | Description                                                                 |
| ------------- | --------------------------------------------------------------------------- |
| Axle Stall    | Stalling on the coping on both trucks before dropping back in.              |
| Blunt         | Stalling with the back wheels on top of the coping and the tail against it. |
| Disaster      | Landing back in with the middle of the board over the coping.               |
| Invert        | Handplant on the coping, body inverted over the board.                      |
| Lip Trick     | Any trick performed on the coping or lip of a ramp, bowl, or pool.          |
| Rock 'n' Roll | Rocking on the coping, pivoting 180, and rolling back in.                   |
| Rock to Fakie | Rocking on the coping and rolling back in fakie, no pivot.                  |
| Stall         | Pausing on the coping on the wheels, trucks, or tail.                       |

### Flip Tricks

| Term                | Description                                                                   |
| ------------------- | ----------------------------------------------------------------------------- |
| 360 Flip (Tre Flip) | Kickflip combined with a 360 pop shuvit.                                      |
| Hardflip            | Kickflip combined with a frontside shuvit.                                    |
| Heelflip            | Board rotates along its length, flicked off the toe-side edge with the heel.  |
| Impossible          | Board wraps vertically around the back foot.                                  |
| Kickflip            | Board rotates along its length, flicked off the heel-side edge with the toes. |
| Pop Shuvit          | Shuvit with pop, so the board leaves the ground.                              |
| Shuvit              | Board spins 180 flat underneath the skater, who does not rotate.              |
| Varial              | Any flip trick combined with a shuvit rotation.                               |
