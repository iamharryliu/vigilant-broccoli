### Assembly

```mermaid
flowchart TD
  Boot -->|mounting bolts| Frame
  Boot --> Liner
  Frame -->|axles| W[Wheels + Bearings]
  Frame --> HB[Heel Brake]
```

| Part     | Description                                                                                | Image                                                                                                                                                                                                                                        |
| -------- | ------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Axles    | Bolts through the wheels that clamp them into the frame; removed to rotate or swap wheels. | ![Axles, bearings and spacers](https://upload.wikimedia.org/wikipedia/commons/thumb/4/41/Inline_skate_bearings.jpg/120px-Inline_skate_bearings.jpg)                                                                                          |

### Mounting

The connection on the boot that the frame bolts to — it decides which frames fit the boot.

| Mount             | Description                                                                                                                         | Image                                                                                                                                                                                                                                                     |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 Point (165mm)   | Two bolts 165mm apart, the recreational standard; came from speed skating and includes ~10mm heel lift.                             |                                                                                                                                                                                                                                                           |
| 2 Point (195mm)   | Two bolts 195mm apart, introduced 2003; fits larger wheels without raising the frame. Mostly speed.                                 |                                                                                                                                                                                                                                                           |
| Trinity (3 Point) | Powerslide's 2016 standard — two front mounts on the sides plus one at the heel, for a lower stance and more direct power transfer. | ![Trinity boot mounting platforms](https://upload.wikimedia.org/wikipedia/commons/thumb/7/7d/Trinity_mounting-Boot_showing_three_mounting_platforms-IMG_3878-bg-FRD.png/120px-Trinity_mounting-Boot_showing_three_mounting_platforms-IMG_3878-bg-FRD.png) |
| UFS               | Universal Frame System — flat mount with no heel lift, used on aggressive skates so the soulplate sits low for grinds.              | ![UFS soulplate and boot](https://upload.wikimedia.org/wikipedia/commons/thumb/2/2a/Razors_Shift_Jeph_Howard_2-UFS_mounting-soulplate_n_boot-IMG_6193-bg-FRD.png/120px-Razors_Shift_Jeph_Howard_2-UFS_mounting-soulplate_n_boot-IMG_6193-bg-FRD.png)      |

### Boot

| Boot   | Construction                                                                                        | Feel                                                                                                 | Image                                                                                                                                                                                                                                   |
| ------ | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hard   | Rigid plastic or carbon shell with a removable padded liner inside.                                 | Stiff and precise, holds the ankle firmly, needs no break-in but is warm and unforgiving on fit.     | ![Hard boot](https://upload.wikimedia.org/wikipedia/commons/thumb/7/7d/Inline_Skate-Hard_boot-Rollerblade-Lightning_TRS-1988-IMG_5703-FRD.png/120px-Inline_Skate-Hard_boot-Rollerblade-Lightning_TRS-1988-IMG_5703-FRD.png)             |
| Hybrid | Soft padded boot built around a carbon or plastic shell, so the shell is inside instead of outside. | Support close to a hard boot with the comfort and weight of a soft one; the usual urban choice.      | ![Hybrid boot with carbon shell](https://upload.wikimedia.org/wikipedia/commons/thumb/b/b8/Hybrid_soft_boot-Inline_skate_with_a_carbon_fiber_shell-PS_Tau.png/120px-Hybrid_soft_boot-Inline_skate_with_a_carbon_fiber_shell-PS_Tau.png) |
| Soft   | Padded fabric boot with a plastic cuff or exoskeleton for support.                                  | Comfortable, light, and breathable straight away, but flexes under hard pushes and wears out sooner. | ![Soft boot](https://upload.wikimedia.org/wikipedia/commons/thumb/5/50/Inline-Skate-Soft-boot-K2-Cadence-SL.png/120px-Inline-Skate-Soft-boot-K2-Cadence-SL.png)                                                                         |

The liner inside a hard or hybrid shell does the fitting, and can be swapped or heat-moulded on its own.

#### Frame Length

The number printed on a frame — 263, 283, 12.8" — is its **length, measured axle centre to axle centre** (the wheelbase), not the overall length of the metal. A 283mm frame therefore sits on a wheelbase 20mm longer than a 263mm one.

| Longer frame (e.g. 283mm)                     | Shorter frame (e.g. 263mm)                         |
| --------------------------------------------- | -------------------------------------------------- |
| More stable at speed, holds a glide           | Turns tighter, easier in crowds and on transitions |
| Longer push, better for distance and marathon | Faster footwork for slalom, hockey, freestyle      |
| Room for bigger wheels (110mm, 125mm)         | Keeps small wheels close together                  |

Typical ranges (manufacturers vary):

| Length         | Typical setup          | Used for                  |
| -------------- | ---------------------- | ------------------------- |
| ~231–245mm     | 4x76–4x80              | Slalom, freestyle, kids   |
| ~245–265mm     | 4x84–4x90, 3x100–3x110 | Urban, all-round          |
| ~265–290mm     | 3x110, 3x125, 4x100    | Fitness, distance         |
| 12.8" (~325mm) | 4x100–4x110, 3x125     | Speed and marathon racing |

Frame length should track boot size; a long frame on a small boot overhangs and steers badly.

### Wheels

| Setup       | Description                                                                                                              | Image                                                                                                                                                                                                                                                                                                       |
| ----------- | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Anti-Rocker | Large outer wheels with small hard or plastic inner wheels, leaving a grind gap for aggressive skating.                  |                                                                                                                                                                                                                                                                                                             |
| Flat        | All wheels the same size, all touching the ground — most speed, stability, and roll.                                     | ![Flat setup lines on a 3x110 frame](https://upload.wikimedia.org/wikipedia/commons/thumb/3/3e/Endless_90_Trinity_inline_skate_frame-Undercover_110mm_wheels-IMG_4095-Rocker_annotated-bg-FRD.png/120px-Endless_90_Trinity_inline_skate_frame-Undercover_110mm_wheels-IMG_4095-Rocker_annotated-bg-FRD.png) |
| Hi-Lo       | Wheels or axle heights stepped so the heel sits higher than the toe, pitching the shin forward. Common on hockey skates. | ![Hi-lo hockey setup](https://upload.wikimedia.org/wikipedia/commons/thumb/a/a9/Hi-Lo_setup_for_natural_dorsiflextion-TRUE_hockey_skates-76mm_AND_80mm_wheels-IMG_3039-bg-FRD.png/120px-Hi-Lo_setup_for_natural_dorsiflextion-TRUE_hockey_skates-76mm_AND_80mm_wheels-IMG_3039-bg-FRD.png)                  |
| Rocker      | Middle wheels sit lower (or outer wheels raised ~2mm), curving the wheelbase for quick turns — freestyle and urban.      |                                                                                                                                                                                                                                                                                                             |
