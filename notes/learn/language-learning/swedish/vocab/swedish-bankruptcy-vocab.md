# Swedish Bankruptcy Vocabulary

| Swedish term | English meaning / definition |
| --- | --- |
| aktiebolagslagen | The Swedish Companies Act. |
| aktieägare | Shareholder. |
| arbetsbefriad | Released from the obligation to work. |
| Arbetsförmedlingen | The Swedish Public Employment Service. |
| arbetsgivaravgifter | Employer social security contributions. |
| arbetstillstånd | Work permit. |
| att ansöka om konkurs | To apply for bankruptcy / file a bankruptcy petition. |
| att försättas i konkurs | To be declared bankrupt by a court. |
| att gå i konkurs | To go bankrupt. |
| att säga upp någon | To terminate someone's employment with notice. |
| betalningsbekräftelse | Payment confirmation. |
| betalningsdröjsmål | Delay in payment / late payment. |
| betalningsskyldighet | Obligation to pay. |
| borgenär | Creditor: a person or organisation owed money. |
| bruttolön | Gross salary, before tax deductions. |
| dröjsmålsränta | Late-payment interest. |
| fackförbund / facket | Trade union / the union. |
| finansiering | Financing / funding. |
| finansieringsåtagande | Funding commitment. |
| fordran | Claim: a right to receive payment from someone. |
| förfallen faktura | Overdue invoice. |
| försäkran | Declaration / statement confirming information. |
| försäkring | Insurance. |
| försäkringspremie | Insurance premium. |
| försäkringsskydd | Insurance coverage. |
| garanti | Guarantee / assurance. |
| gäldenär | Debtor: a person or organisation that owes money. |
| innestående lön | Outstanding wages: salary earned but not yet paid. |
| kapitaltillskott | Capital injection. |
| konkurs | Bankruptcy. |
| konkursansökan | Bankruptcy application / petition. |
| konkursbeslut | Court decision declaring bankruptcy. |
| konkursbo | Bankruptcy estate: the assets administered during bankruptcy. |
| konkursförvaltare | Bankruptcy administrator / trustee, appointed by the court. |
| kundbetalning | Customer payment. |
| likviditetsproblem | Liquidity problems / cash-flow difficulties. |
| lönefordran | Wage claim: an employee's claim for unpaid salary. |
| lönegarantibeslut | Decision establishing entitlement to wage guarantee and its amount. |
| löneutbetalning | Salary payment / payroll payment. |
| majoritetsägare | Majority shareholder. |
| obestånd / insolvens | Insolvency: inability to pay debts that is not merely temporary. |
| referensränta | Reference interest rate. |
| semesterersättning | Compensation for accrued holiday entitlement, for example when employment ends. |
| semesterlön | Holiday pay during paid annual leave. |
| skatteavdrag | Tax deduction / withholding from salary. |
| statlig lönegaranti | State wage guarantee: compensation that can cover eligible unpaid wages in bankruptcy or company restructuring. |
| styrelse | Board of directors. |
| styrelseledamot | Board member. |
| styrelseordförande | Chair of the board. |
| tingsrätt | District court. |
| tjänstepension | Occupational pension / employer pension. |
| transaktionskvitto | Transaction receipt. |
| uppehållstillstånd | Residence permit. |
| uppsägning | Termination with notice; can also refer to termination of a policy or agreement. |
| uppsägningslön | Salary during the notice period. |
| uppsägningstid | Notice period. |
| utebliven lön | Unpaid / missing salary. |
| verkställande direktör (vd) | Chief executive officer (CEO). |
