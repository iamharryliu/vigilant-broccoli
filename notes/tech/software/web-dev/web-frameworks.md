## Frontend

| Framework / Library                                            | Description                                                                                                                              | Language                | Best used for                                                                                                 | Industries / examples                                                                                                                                                               |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Angular](https://angular.dev/overview)                        | Frontend framework with components, dependency injection, routing, forms, and an integrated toolchain.                                   | TypeScript              | Large application interfaces and teams that benefit from shared architectural conventions.                    | [Cloud infrastructure (Google Cloud), developer/design tools (Google Fonts)](https://angular.dev/overview).                                                                         |
| [Astro](https://docs.astro.build/en/concepts/why-astro/)       | Web framework that renders HTML and adds client-side JavaScript through interactive islands.                                             | JavaScript / TypeScript | Blogs, documentation, marketing sites, and other content-heavy websites.                                      | [Retail (IKEA), consumer goods (Unilever), automotive (Porsche), nonprofit/public sector (UNDP)](https://astro.build/showcase/).                                                    |
| [Ember.js](https://emberjs.com/)                               | Frontend framework with strong conventions, integrated routing, and coordinated tooling.                                                 | JavaScript / TypeScript | Long-lived web applications where consistent structure across a team matters.                                 | [Professional networking (LinkedIn)](https://www.linkedin.com/blog/engineering/archive/ember-meetup--engines-at-linkedin).                                                          |
| [Gatsby](https://www.gatsbyjs.com/docs/)                       | React-based site framework with a data layer and integrations for content sources.                                                       | JavaScript / TypeScript | Content websites that benefit from Gatsby's CMS integrations and existing plugin ecosystem.                   | [E-commerce, publishing, and software/SaaS](https://www.gatsbyjs.com/showcase/).                                                                                                    |
| [Next.js](https://nextjs.org/docs)                             | React application framework with routing, server rendering, static generation, and server-side functionality.                            | JavaScript / TypeScript | Full-stack React applications, storefronts, and websites combining interactive UI with server-rendered pages. | [Retail (Nike), financial services (Stripe/NerdWallet), AI software (OpenAI)](https://nextjs.org/showcase).                                                                         |
| [Nuxt](https://nuxt.com/docs/4.x/getting-started/introduction) | Vue application framework with routing, server rendering, static generation, and the Nitro server engine.                                | JavaScript / TypeScript | Full-stack Vue applications, content sites, and applications needing hybrid rendering.                        | [Aerospace/public sector (NASA JPL), software (Microsoft Edge), advertising (TikTok Ads)](https://nuxt.com/showcase).                                                               |
| [Preact](https://preactjs.com/)                                | Small component-based UI library with a React-like API and optional React compatibility layer.                                           | JavaScript / TypeScript | Embedded widgets and interactive interfaces with a tight JavaScript bundle budget.                            | [Automotive e-commerce (Truebil, documented production migration)](https://web.dev/case-studies/truebil-lite).                                                                      |
| [Qwik](https://qwik.dev/)                                      | UI framework using resumability and lazy loading to defer browser work until needed.                                                     | JavaScript / TypeScript | Interactive websites where startup JavaScript and time to interaction are central concerns.                   | [Healthcare (Sasthya Seba), automotive (Honda Türkiye), insurance (QuoteMingle)](https://qwik.dev/showcase/).                                                                       |
| [React](https://react.dev/)                                    | Component-based UI library for declarative interfaces; routing and application structure come from additional tools or frameworks.       | JavaScript / TypeScript | Interactive web interfaces and reusable component systems with access to a broad ecosystem.                   | [Social media (Facebook), streaming media (Netflix), publishing software (WordPress)](https://engineering.fb.com/2015/12/29/developer-tools/open-source-in-2015-a-year-of-growth/). |
| [React Router](https://reactrouter.com/start/modes)            | React routing library whose framework mode adds data loading, actions, code splitting, and server rendering.                             | JavaScript / TypeScript | Route-driven React applications, form-heavy workflows, and full-stack applications using framework mode.      | [Retail/e-commerce through the Shopify app ecosystem](https://shopify.dev/docs/apps/build/build?framework=reactRouter).                                                             |
| [SolidJS](https://docs.solidjs.com/)                           | UI library using fine-grained reactivity and JSX to update the DOM without a virtual DOM.                                                | JavaScript / TypeScript | Highly reactive interfaces where targeted updates and low rendering overhead matter.                          | [Streaming media and broadcasting (Angel Studios, Bell Fibe TV, CHEK News through SolidTV)](https://solidtv.dev/).                                                                  |
| [Svelte](https://svelte.dev/docs/svelte/overview)              | Compiler-based UI framework using component templates and reactive state.                                                                | JavaScript / TypeScript | Interactive interfaces and reusable components with concise templates and compiler-driven updates.            | [Publishing (The New York Times), retail (Decathlon), cybersecurity (1Password/Mullvad)](https://svelte.dev/).                                                                      |
| [SvelteKit](https://svelte.dev/docs/kit/introduction)          | Svelte application framework with routing, server rendering, data loading, form actions, and deployment adapters.                        | JavaScript / TypeScript | Full-stack Svelte applications, server-rendered websites, and form-driven workflows.                          | [Publishing (The New York Times), consumer electronics retail (dbrand), software/SaaS](https://github.com/vitejs/companies-using-vite).                                             |
| [TanStack Start](https://tanstack.com/start/latest)            | Full-stack React and Solid framework with type-safe routing, server rendering, streaming, and server functions built on TanStack Router. | JavaScript / TypeScript | Full-stack applications with complex routing, URL state, and typed communication between client and server.   | [AI software (T3 Chat/Anara), workflow infrastructure (Inngest), product analytics (OpenPanel)](https://tanstack.com/showcase).                                                     |
| [Vue.js](https://vuejs.org/guide/introduction.html)            | Progressively adoptable UI framework with reactive state, HTML-based templates, and reusable components.                                 | JavaScript / TypeScript | Interactive web applications and adding component-based UI to existing websites incrementally.                | [Developer software/SaaS (GitLab)](https://docs.gitlab.com/development/fe_guide/frontend_goals/).                                                                                   |

## Backend

| Framework / Library                                              | Description                                                                                                                | Language                | Best used for                                                                                           | Industries / examples                                                                                                                                                                                                                            |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [AdonisJS](https://adonisjs.com/)                                | Node.js framework with integrated routing, authentication, validation, ORM, and application conventions.                   | TypeScript              | Database-backed web applications and APIs where an integrated backend reduces setup work.               | [Automotive (Renault), publishing (Marie Claire), cryptocurrency (Ledger)](https://adonisjs.com/).                                                                                                                                               |
| [Express](https://expressjs.com/)                                | Minimal Node.js server framework built around routing and middleware.                                                      | JavaScript / TypeScript | REST APIs, small backend services, and applications requiring control over the supporting stack.        | [Publishing and membership software (Ghost, whose backend declares Express as a dependency)](https://github.com/TryGhost/Ghost/blob/main/ghost/core/package.json).                                                                               |
| [Fastify](https://fastify.dev/)                                  | Node.js server framework emphasizing low overhead, plugins, and schema-based validation and serialization.                 | JavaScript / TypeScript | APIs and backend services where request throughput, validation, and plugin isolation matter.            | [Mobility (CAR2GO), media infrastructure (Gumlet), cybersecurity (Vectra)](https://openjsf.org/blog/web-framework-fastify-joins-openjs-foundation-as-an-incubating-project).                                                                     |
| [FeathersJS](https://feathersjs.com/)                            | Service-based framework exposing APIs over HTTP and real-time transports.                                                  | JavaScript / TypeScript | Chat, collaborative applications, live dashboards, and CRUD APIs with real-time updates.                | [Financial services (Confinze)](https://www.imaginarycloud.com/project/confinze); [healthcare (patient-management platform built by ScienceSoft)](https://www.scnsoft.com/case-studies/mvp-development-of-a-platform-for-patients-with-obesity). |
| [hapi](https://hapi.dev/)                                        | Node.js server framework with configuration-driven routing, validation, authentication, and plugins.                       | JavaScript / TypeScript | Backend APIs requiring explicit server configuration and integrated request handling.                   | [Retail/e-commerce (Walmart)](https://hapi.dev/).                                                                                                                                                                                                |
| [Hono](https://hono.dev/)                                        | Lightweight server framework built on Web Standard Request and Response APIs across multiple runtimes.                     | JavaScript / TypeScript | Edge functions, serverless APIs, and services that need runtime portability.                            | [Cloud infrastructure (Cloudflare D1/KV), identity services (Clerk/Unkey), developer SaaS (OpenStatus)](https://hono.dev/docs).                                                                                                                  |
| [Koa](https://koajs.com/)                                        | Small Node.js server framework using async middleware with few bundled features.                                           | JavaScript / TypeScript | Custom backend stacks where a compact middleware foundation is preferable to an integrated framework.   | [Content management and publishing software (Strapi)](https://strapi.io/blog/strapi-architecture).                                                                                                                                               |
| [Meteor](https://docs.meteor.com/)                               | Full-stack platform integrating frontend applications, server code, and reactive data synchronization.                     | JavaScript / TypeScript | Real-time applications and prototypes using Meteor's integrated application and data model.             | [Business communications (Rocket.Chat), recruiting software (CodeSignal), sales software (Lemlist)](https://www.meteor.com/).                                                                                                                    |
| [NestJS](https://docs.nestjs.com/)                               | Node.js backend framework with modules, dependency injection, and Express or Fastify adapters.                             | TypeScript / JavaScript | Large backend applications, team-owned APIs, and services needing consistent module boundaries.         | [Healthcare (Komed Health), retail (Rozetka), logistics (Swyft Logistics)](https://docs.nestjs.com/discover/companies).                                                                                                                          |
| [Spring Boot](https://spring.io/projects/spring-boot/)           | Builds on Spring with auto-configuration, starter dependencies, embedded servers, and operational features.                | Java / Kotlin           | Standalone JVM web applications, REST APIs, and production services with reduced configuration work.    | [Streaming media (Netflix)](https://netflixtechblog.com/netflix-oss-and-spring-boot-coming-full-circle-4855947713a0); [retail (Target)](https://tech.target.com/blog/spring-boot-service-to-service-communication).                              |
| [Spring Framework](https://spring.io/projects/spring-framework/) | JVM application framework providing dependency injection, transactions, data integration, and MVC or reactive web support. | Java / Kotlin           | Enterprise JVM applications and systems requiring extensive integration and control over configuration. | [Streaming media and retail/e-commerce](https://spring.io/why-spring/).                                                                                                                                                                          |
