## Native Device Features

| Feature                 | Capability                                                                                                    | Common App Uses                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Background Tasks        | Run scheduled or event-driven work while an app is not in the foreground, subject to operating system limits. | Data synchronization, uploads, and location tracking.                  |
| Biometrics              | Use system authentication with fingerprints or facial recognition.                                            | Unlocking apps and confirming sensitive actions.                       |
| Bluetooth               | Communicate with nearby compatible devices, including Bluetooth Low Energy peripherals.                       | Wearables, fitness sensors, and smart home accessories.                |
| Camera                  | Capture photos and videos or process a live camera feed.                                                      | QR scanning, document scanning, profile photos, and augmented reality. |
| Contacts                | Read or update the device's address book with permission.                                                     | Contact selection, invitations, and caller identification.             |
| Files and Media Library | Select, read, and save documents, photos, and videos through device storage APIs and system pickers.          | Attachments, photo uploads, downloads, and media editing.              |
| Haptics                 | Trigger vibration or tactile feedback.                                                                        | Confirming actions, game feedback, and interaction cues.               |
| Location                | Obtain device location and monitor location changes or geographic regions.                                    | Maps, navigation, delivery tracking, and nearby services.              |
| Microphone              | Record audio or process live audio input.                                                                     | Voice messages, calls, speech input, and music recording.              |
| Motion Sensors          | Read accelerometer, gyroscope, and other supported sensor data.                                               | Activity tracking, orientation controls, and games.                    |
| NFC                     | Interact with supported nearby tags or devices using Near Field Communication.                                | Tag scanning, device setup, and supported access credentials.          |
| Notifications           | Display local alerts or receive push messages through platform services.                                      | Reminders, chat messages, and order updates.                           |
| Secure Storage          | Store credentials and other small sensitive values using operating system security facilities.                | Session tokens and encryption keys.                                    |
| Sharing                 | Send content to other apps through the system share interface.                                                | Sharing links, photos, documents, and exported reports.                |
| Widgets                 | Display app information or supported actions on system surfaces such as the home screen.                      | Weather summaries, calendars, and habit progress.                      |
