# Netlify

Static hosting + serverless/edge functions, similar to [Cloudflare Pages](./cloudflare-pages.md) — alternative when forms/identity add-ons are needed.

## Free Tier

Starter plan — free. Exceeding a limit suspends the site for the rest of the calendar month rather than billing overage.

- Bandwidth: 100GB/month. Build minutes: 300/month.
- Serverless function invocations: 125,000/month. Edge function invocations: 1,000,000/month.
- Accounts created after September 2025 use a credits system instead (300 credits/month; deploys cost 15 credits, bandwidth 20 credits/GB, compute 10 credits/GB-hour, requests 2 credits/10K).
