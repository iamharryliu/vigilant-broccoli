# Lovable

AI app builder that generates and hosts full-stack web apps from prompts, with an optional Supabase-backed "Lovable Cloud" for backend/data.

## Free Tier

No credit card required.

- 5 daily build credits (reset midnight UTC), capped at 30/month — unused daily credits don't roll over.
- 20 Lovable Cloud credits/month for backend usage.
- Up to 5 public projects, hosted on `lovable.app` subdomains; unlimited workspace collaborators.
- No custom domains and no "Code mode" (direct source editing) on the free plan.
