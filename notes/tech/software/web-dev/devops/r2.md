# Cloudflare R2

S3-compatible object storage with zero egress fees. See [Cloudflare](./cloudflare.md) for the broader Wrangler/Pages/Workers context.

## Table of Contents

- [Commands](#commands)
- [Free Tier](#free-tier)
- [References](#references)

## Commands

- Configure access tokens to access desired buckets.

```
wrangler r2 bucket create [YOUR_BUCKET_NAME]
wrangler r2 bucket list
wrangler r2 bucket delete [BUCKET_TO_DELETE]
```

## Free Tier

Always free each month (no expiry):

| Resource                           | Free allowance              |
| ---------------------------------- | --------------------------- |
| Storage                            | 10 GB / month               |
| Class A operations (writes, lists) | 1 million requests / month  |
| Class B operations (reads)         | 10 million requests / month |
| Egress (data transfer out)         | Free, unlimited             |
