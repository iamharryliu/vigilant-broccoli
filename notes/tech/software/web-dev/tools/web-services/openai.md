## Free Tier

OpenAI offers free daily usage on traffic shared with OpenAI (data sharing program):

- Up to 250 thousand tokens per day across gpt-5.4, gpt-5.2, gpt-5.1, gpt-5, gpt-4.1, gpt-4o, o1 and o3.
- Up to 2.5 million tokens per day across gpt-5.4-mini, gpt-5.4-nano, gpt-5-mini, gpt-5-nano, gpt-4.1-mini, gpt-4.1-nano, gpt-4o-mini, o3-mini and o4-mini.

Usage beyond these limits, and other models (such as GPT-5.5), is billed by token usage at standard rates; some limitations apply. See the [official model documentation](https://developers.openai.com/api/docs/models) for pricing and rate limits.
