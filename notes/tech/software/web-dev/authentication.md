# Authentication

| Term  | Description                                                                                                                                               |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JWT   | JSON Web Token. A signed, self-contained token carrying claims (such as user id and expiry) that a server can verify without a session lookup.            |
| OAuth | Authorization framework that lets an app access a user's resources on another service through a limited-scope access token, without sharing the password. |
| OIDC  | OpenID Connect. An identity layer on top of OAuth 2.0 that adds an ID token so an app can learn who the user is, not just what they can access.           |
| SSO   | Single Sign-On. One login that grants access to multiple applications, typically through an identity provider using OIDC or SAML.                         |
