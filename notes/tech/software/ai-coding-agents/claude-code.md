# Claude Code

```sh
claude # open the interactive session in the current directory

/status # show version, model, account, and connectivity
/login # sign in or switch accounts
/logout # sign out of the current account
/usage # show plan usage and rate limits

# CONTEXT HANDLING
/compact # summarize the conversation to free up context
/clear # start a fresh conversation with empty context
/rewind # roll the conversation or code back to an earlier checkpoint
/resume # pick up a previous conversation

# SETTINGS
/config # open the settings interface
/model # choose the active model

CLAUDE.md # project instructions file Claude Code reads at session start
```
