# Software Timeline

Revolutionary tools/implementations and when they gained public (mainstream) traction — not necessarily their invention date.

| Tool/Implementation      | Public Traction | Originated | Notes                                   |
| ------------------------ | --------------- | ---------- | --------------------------------------- |
| Unix                     | ~1975           | 1969       | AT&T Bell Labs; spread via universities |
| Relational Databases/SQL | ~1979           | 1970       | Oracle v2 first commercial SQL RDBMS    |
| GUI (Desktop)            | 1984            | 1973       | Xerox PARC → Apple Macintosh            |
| MS-DOS/PC Software       | 1981            | 1981       | IBM PC launch                           |
| Spreadsheets             | 1983            | 1979       | VisiCalc → Lotus 1-2-3                  |
| Internet (TCP/IP)        | 1983            | 1969       | ARPANET → TCP/IP standardization        |
| World Wide Web           | 1994            | 1991       | Mosaic/Netscape drove public adoption   |
| Email (Public)           | 1996            | 1971       | Hotmail/webmail brought it to consumers |
| Open Source/Linux        | 1998            | 1991       | Netscape open-sourcing, Red Hat IPO     |
| Search Engines           | 1998            | 1990       | Google overtakes AltaVista/Yahoo        |
| E-commerce               | 1999            | 1995       | Amazon/eBay reach mainstream            |
| Instant Messaging        | 1999            | 1996       | AIM/ICQ                                 |
| Wikis/Wikipedia          | 2003            | 1995       | Wikipedia surpasses early wiki niche    |
| Social Media             | 2006            | 2004       | Facebook opens to the public            |
| Version Control (Git)    | 2008            | 2005       | GitHub drives public/OSS adoption       |
| Smartphones/App Stores   | 2008            | 2007       | iPhone App Store                        |
| Cloud Computing          | 2010            | 2006       | AWS EC2/S3 reach mainstream enterprise  |
| Containers (Docker)      | 2014            | 2013       | Docker adoption surges                  |
| Modern JS Frameworks     | 2015            | 2013       | React/Angular/Vue mainstream adoption   |
| Video Conferencing       | 2020            | 2011       | Zoom during COVID-19 pandemic           |
| No-Code/Low-Code         | 2021            | 2016       | Notion/Airtable/Webflow mainstream      |
| Generative AI/LLMs       | 2023            | 2018       | ChatGPT public launch (Nov 2022)        |
