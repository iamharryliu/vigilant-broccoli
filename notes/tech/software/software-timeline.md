## Software Adoption Timeline

Approximate adoption eras and notable public milestones. Origins refer to the named implementation or an early precursor; broad categories do not have a single invention or mainstream-adoption date.

| Tool/Implementation      | Public Traction | Originated              | Notes                                                                                                                                                                                                     |
| ------------------------ | --------------- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unix                     | ~1975           | 1969                    | AT&T Bell Labs; spread via universities                                                                                                                                                                   |
| Relational Databases/SQL | ~1979           | 1970                    | Oracle v2: early commercial SQL RDBMS                                                                                                                                                                     |
| MS-DOS/PC Software       | 1981            | 1981                    | IBM PC launch                                                                                                                                                                                             |
| Spreadsheets             | 1983            | 1979                    | VisiCalc → Lotus 1-2-3                                                                                                                                                                                    |
| Internet (TCP/IP)        | 1983            | 1969                    | ARPANET → TCP/IP standardization                                                                                                                                                                          |
| GUI (Desktop)            | 1984            | 1973                    | Xerox PARC → Apple Macintosh                                                                                                                                                                              |
| Web Search Engines       | 1990s–2000      | 1990 (Archie precursor) | Google launched in 1998; [its billion-URL index in 2000](https://googlepress.blogspot.com/2000/06/google-launches-worlds-largest-search.html) is a scale milestone, not a date for overtaking competitors |
| World Wide Web           | 1994            | 1991                    | Mosaic/Netscape drove public adoption                                                                                                                                                                     |
| Email (Public)           | 1996            | 1971                    | Hotmail/webmail brought it to consumers                                                                                                                                                                   |
| Open Source/Linux        | 1998–1999       | 1991 (Linux)            | [Netscape source release in 1998](https://www.mozilla.org/en-US/about/history/); [Red Hat IPO in August 1999](https://www.redhat.com/en/blog/25-things-you-should-know-about-red-hat-0)                   |
| E-commerce               | 1999            | 1995                    | Amazon/eBay reach mainstream                                                                                                                                                                              |
| Instant Messaging        | 1999            | 1996                    | AIM/ICQ                                                                                                                                                                                                   |
| Social Media             | 2000s           | Before 2004             | Facebook opened to the public in 2006; social networking predates Facebook                                                                                                                                |
| Wikis/Wikipedia          | 2003            | 1995                    | Wikipedia surpasses early wiki niche                                                                                                                                                                      |
| Version Control (Git)    | 2008            | 2005                    | GitHub drives public/OSS adoption                                                                                                                                                                         |
| Smartphones/App Stores   | 2008            | Before 2007             | iPhone App Store launch; smartphones and mobile software distribution predate the iPhone                                                                                                                  |
| Cloud Computing          | ~2010           | Before 2006             | AWS S3/EC2 launched in 2006; enterprise adoption grew afterward                                                                                                                                           |
| No-Code/Low-Code         | ~2010s–2020s    | Before 2016             | Products such as Notion, Airtable, and Webflow expanded access; visual application builders predate these products                                                                                        |
| Containers (Docker)      | 2014            | 2013                    | Docker adoption surges                                                                                                                                                                                    |
| Modern JS Frameworks     | ~2015–2018      | Before 2013             | React, Angular, and Vue adoption grew at different times; see the version-specific timeline below                                                                                                         |
| Video Conferencing       | 2020            | 2011                    | Zoom during COVID-19 pandemic                                                                                                                                                                             |
| Generative AI/LLMs       | 2022–2023       | Before 2018             | [ChatGPT public launch in November 2022](https://openai.com/index/chatgpt/) helped popularize conversational LLMs; generative AI research predates GPT                                                    |
