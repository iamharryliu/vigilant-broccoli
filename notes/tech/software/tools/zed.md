## Keyboard Shortcuts

Default macOS shortcuts from [Zed's keymap](https://github.com/zed-industries/zed/blob/main/assets/keymaps/default-macos.json). Custom keymaps can override them. For a two-step shortcut, release the first combination before pressing the next key.

| Action                            | Shortcut (Mac)      | Command palette action               | Context                                                                                                         |
| --------------------------------- | ------------------- | ------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| Focus file explorer               | `cmd + shift + E`   | `project panel: toggle focus`        | Opens/focuses the file explorer, or returns focus to the editor.                                                |
| Open command palette              | `cmd + shift + P`   | `command palette: toggle`            | Search for and run editor commands.                                                                             |
| Open Markdown preview             | `cmd + shift + V`   | `markdown: open preview`             | Focus a Markdown file.                                                                                          |
| Open Markdown preview to the side | `cmd + K`, then `V` | `markdown: open preview to the side` | Focus a Markdown file.                                                                                          |
| Open new terminal                 | `ctrl + ~`          | `workspace: new terminal`            | Creates another terminal; see [terminal documentation](https://zed.dev/docs/terminal).                          |
| Quick Open (file search)          | `cmd + P`           | `file finder: toggle`                | Search project files by name and open the selected file.                                                        |
| Show / hide file explorer         | `cmd + B`           | `workspace: toggle left dock`        | Shows or hides the left dock, where the file explorer lives by default; also affects other panels in that dock. |
| Toggle Git panel focus            | `ctrl + shift + G`  | `git panel: toggle focus`            | Opens/focuses the Git panel, or returns focus to the editor.                                                    |
| Toggle terminal panel             | ``ctrl + ` ``       | `terminal panel: toggle`             | Shows or hides the terminal panel.                                                                              |
