# Code Quality Tools

| Tool | Purpose | Configuration | Enforcement (local/CI) |
| --- | --- | --- | --- |
| Agent adapter check | Fails when a `CONTEXT.md` or shared skill is missing a tracked `AGENTS.md`/command symlink | [ci-pr-check.yml](../.github/workflows/ci-pr-check.yml) (`Verify agent adapters` step) | CI: `pre-commit` job in `ci-pr-check`. No local hook. |
| Agent sandbox image build | Builds the sandbox Dockerfile to catch a broken mise pin, download or apt error | [test-smoke-agent-sandbox-image.yml](../.github/workflows/test-smoke-agent-sandbox-image.yml) | CI only: pull requests and `main` pushes touching `infrastructure/agent-sandbox/**`; build only, never pushed. |
| Black | Formats Python | [.pre-commit-config.yaml](../.pre-commit-config.yaml) | Local: pre-commit hook. CI: `pre-commit` job in `ci-pr-check`. |
| commitlint | Enforces the commit contract (`<type>(<scope>): <Capitalized subject>.`) on commits and PR titles | [commitlint.config.mjs](../commitlint.config.mjs), [.pre-commit-config.yaml](../.pre-commit-config.yaml) | CI only: `commitlint` job in `ci-pr-check` (PR title and PR commits; skipped only for `dependabot[bot]` and `renovate[bot]` PRs). |
| Dependabot | Opens weekly dependency update PRs for npm and GitHub Actions | [dependabot.yml](../.github/dependabot.yml) | CI: GitHub-hosted service; opens PRs that run `ci-pr-check`. No local enforcement. |
| ESLint | Lints TypeScript/JavaScript in the Nx workspace | [eslint.config.mjs](../projects/nx-workspace/eslint.config.mjs) | Local: nx-workspace `lint-staged` config (`nx affected -t lint`). CI: `nx affected -t lint test build` in `ci-pr-check`. |
| ESLint `require-dark-variant` rule | Fails `**/*.tsx` static `className`/`cn`/`clsx` strings with a light-only `bg-white`, `bg-gray-*`, `border-gray-*` or `text-gray-*` utility lacking a `dark:` utility of the same property | [require-dark-variant.cjs](../projects/nx-workspace/tools/eslint-rules/require-dark-variant.cjs), [dark-variant-config.cjs](../projects/nx-workspace/tools/eslint-rules/dark-variant-config.cjs), [eslint.config.mjs](../projects/nx-workspace/eslint.config.mjs) | Local and CI: runs inside the ESLint row's `nx affected -t lint`. Exempt with `// eslint-disable-next-line vigilant-broccoli/require-dark-variant -- <reason>`; guidance in [ui-app-pattern.md](./app-development/ui/ui-app-pattern.md#consistency-requirements). |
| Gitleaks | Scans git history for committed secrets | [.gitleaks.toml](../.gitleaks.toml) | CI: `gitleaks` job in [deploy.yml](../.github/workflows/deploy.yml) on push, gating the deploy jobs. No local hook. |
| Grind 75 Python tests (`unittest`) | Runs the algorithm practice tests | [.pre-commit-config.yaml](../.pre-commit-config.yaml) | Local: pre-commit hook when `projects/grind-75/python/` changes. CI: skipped via `SKIP` in `ci-pr-check`. |
| Jest | Unit tests for Nx projects using the Jest executor | [jest.config.ts](../projects/nx-workspace/jest.config.ts), [jest.preset.js](../projects/nx-workspace/jest.preset.js), [nx.json](../projects/nx-workspace/nx.json) | CI: `nx affected -t lint test build` in `ci-pr-check`. Local: optional `nx test`. |
| lint-staged | Runs Prettier over staged files | [package.json](../package.json) (`lint-staged`), [format-staged.sh](../scripts/shell/format-staged.sh) | Local: pre-commit hook. CI: skipped via `SKIP` in `ci-pr-check`. Agent sandbox commits: skipped via `SKIP_COMMIT_HOOKS` in `commit-subject.sh` (the clone has no workspace install); `run-pre-commit.sh` runs `format-changed.sh` instead. |
| Markdown table filter (`mdtable`) | Commits Markdown tables unpadded so a row edit diffs and merges as one line; checkout re-aligns them with Prettier for the working tree | [.gitattributes](../.gitattributes), [.gitconfig](../setup/dotfiles/.gitconfig) (`[filter "mdtable"]`), [md-table-filter.mjs](../scripts/node/md-table-filter.mjs), [md-table-compact.mjs](../scripts/node/md-table-compact.mjs) | Local and agent sandbox: Git runs the filter on `git add` and checkout once the dotfile `.gitconfig` is linked (machine setup and sandbox entrypoint). `md-table-compact` pre-commit hook: checks the staged copy when the filter is configured, otherwise compacts the working file and fails. CI: `pre-commit` job in `ci-pr-check`. |
| nvim/tmux config smoke test | Boots the custom nvim and tmux configs to catch breakage | [.pre-commit-config.yaml](../.pre-commit-config.yaml), [config-smoketest.sh](../setup/dotfiles/common/scripts/config-smoketest.sh) | Local: pre-commit hook when nvim/tmux dotfiles change. CI: `pre-commit` job in `ci-pr-check`. |
| Playwright | End-to-end tests for `component-library` and `vb-manager-next` | [component-library playwright.config.ts](../projects/nx-workspace/apps/ui/component-library/e2e/playwright.config.ts), [vb-manager-next playwright.config.ts](../projects/nx-workspace/apps/ui/vb-manager-next/e2e/playwright.config.ts) | CI: `component-library` e2e in `ci-pr-check` when affected. `vb-manager-next` e2e is optional and not wired into CI. |
| pre-commit | Hook framework that runs the hooks in this table at `pre-commit` and `commit-msg` | [.pre-commit-config.yaml](../.pre-commit-config.yaml) | Local: installed by `pre-commit install` in the machine setup. CI: `pre-commit` job in `ci-pr-check`. |
| pre-commit-hooks (`trailing-whitespace`, `end-of-file-fixer`, `check-yaml`) | Fixes trailing whitespace and final newlines, and validates YAML syntax | [.pre-commit-config.yaml](../.pre-commit-config.yaml) | Local: pre-commit hook. CI: `pre-commit` job in `ci-pr-check`. |
| Prettier | Formats JS/TS/JSON/HTML/CSS/Markdown | [.prettierrc.json](../.prettierrc.json), [nx-workspace .prettierrc.json](../projects/nx-workspace/.prettierrc.json), [format-changed.sh](../scripts/shell/format-changed.sh) | Local: via `lint-staged`. Agent sandbox: `format-changed.sh` before each commit. CI: `pre-commit` job in `ci-pr-check` checks the PR's changed files with `format-changed.sh --check` (lockfile Prettier version, Markdown tables compared compact). Optional: `pnpm format`. |
| Renovate | Dependency update configuration (grouping, major-version approval) | [renovate.json](../renovate.json) | CI: installed GitHub app with repository configuration; opens PRs that run `ci-pr-check`. No workflow or hook in this repository runs it, and no local enforcement. |
| repo-stats | Keeps the managed app/service/image/package counts in README, about and resume current | [repo-stats.mjs](../scripts/node/repo-stats.mjs) | Local: pre-commit hook rewrites stale counts. CI: `pre-commit` job in `ci-pr-check` fails on a stale copy. |
| spellcheck | Spell-checks the current directory | [docs-spell-check skill](../setup/dotfiles/agent-skills/docs-spell-check/SKILL.md) | Optional: run manually through the `docs-spell-check` skill. Not enforced. |
| Vitest | Unit tests for Nx projects using the Vitest executor | [vitest.config.ts](../projects/nx-workspace/vitest.config.ts), [nx.json](../projects/nx-workspace/nx.json) | CI: `nx affected -t lint test build` in `ci-pr-check`. Local: optional `nx test`. |
| Vulnerability audit (`vuln_tree.py`) | Prints a dependency vulnerability tree | [vuln_tree.py](../scripts/python/vuln_tree.py) | Optional: `pnpm audit`. Not enforced. |
