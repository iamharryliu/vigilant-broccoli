# Simple Todo App

A self-contained static HTML page with vanilla JavaScript that allows users to add, complete, and delete todos. Todos are persisted in localStorage so they persist between page reloads.

## Features

- Add new todos by typing and pressing Enter or clicking "Add"
- Mark todos as complete/incomplete using checkboxes
- Delete todos with the delete button
- Todos are saved in localStorage and persist between page reloads
- Responsive design that works on mobile and desktop

## Implementation Details

This todo app is implemented as a single HTML file with:
- Pure vanilla JavaScript (no frameworks)
- CSS styling included in the `<style>` tag
- LocalStorage for data persistence
- Event delegation for handling user interactions
- Responsive design using flexbox

The app follows modern web development practices while keeping the implementation simple and self-contained.
