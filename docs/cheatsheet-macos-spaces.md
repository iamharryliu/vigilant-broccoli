# Cheatsheet — macOS Spaces

Caps Lock and Space shortcuts from `setup/dotfiles/macos/karabiner/karabiner.json` and `setup/dotfiles/macos/hammerspoon/init.lua`. Hyper = Cmd + Ctrl + Opt + Shift.

## Caps Lock (Karabiner)

| Key | Action |
| --- | --- |
| Caps Lock double-tap | Toggle real Caps Lock |
| Caps Lock hold | Hyper |
| Caps Lock tap | Escape |

## Hyper (Hammerspoon)

| Key | Action |
| --- | --- |
| Hyper + / | Pick a Space by name |
| Hyper + 1–9 | Go to Space N and show the grid until released |
| Hyper + Arrows | Move across the 3-column Space grid and show it until released |
| Hyper + G | Toggle the Space grid |
| Hyper + N | Rename the current Space |
| Hyper + R | Reload Hammerspoon |
