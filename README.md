## Development

### Commands

```
pnpm i                             # Install root dependencies, then projects/nx-workspace via the root postinstall hook
pnpm cheatsheet                    # Print the CLI command cheatsheet
pre-commit install                 # Install the pre-commit git hooks
pnpm local:install:machine-setup   # Install tools and dotfiles for this machine (macOS or Linux)
```

See more:

- [Cheatsheet](https://context.harryliu.dev/?file=docs/cheatsheet.md) — useful infra-level CLI commands
- [Code quality tools](./docs/code-quality-tools.md) — linters, formatters, hooks and scanners with their local/CI enforcement
- [Alias cheatsheet](https://context.harryliu.dev/?file=docs/cheatsheet-aliases.md) — shell aliases from `setup/dotfiles/`

| Maintain | `agentic-pr-create-audit` — Remove or rewrite docs describing legacy implementations that no longer apply.         | [manual-agentic-pr-create-audit](https://github.com/iamharryliu/vigilant-broccoli/actions/workflows/manual-agentic-pr-create-audit.yml)             | `pnpm agentic-pr-create-audit`                                                                                                                                    | `/agentic-pr-create-audit`                                             |
| Maintain | `agentic-pr-create-context-audit` — Slim duplicated agent guidance and incident narrative without losing context.  | [cron-agentic-pr-create-context-audit](https://github.com/iamharryliu/vigilant-broccoli/actions/workflows/cron-agentic-pr-create-context-audit.yml) | `pnpm agentic-pr-create-context-audit`                                                                                                                            | `/agentic-pr-create-context-audit`                                     |
| Maintain | `agentic-pr-create-prune` — Remove dead code, unused dependencies and stale docs that nothing references.          | [cron-agentic-pr-create-prune](https://github.com/iamharryliu/vigilant-broccoli/actions/workflows/cron-agentic-pr-create-prune.yml)                 | `pnpm agentic-pr-create-prune`                                                                                                                                    | `/agentic-pr-create-prune`                                             |
| Maintain | `agentic-pr-create-todo-audit` — Verify existing TODO rows, remove resolved entries, and correct stale references. | [cron-agentic-pr-create-todo-audit](https://github.com/iamharryliu/vigilant-broccoli/actions/workflows/cron-agentic-pr-create-todo-audit.yml)       | `pnpm agentic-pr-create-todo-audit`                                                                                                                               | `/agentic-pr-create-todo-audit`                                        |

The update workflow selects `change`, `fix-ci`, or `resolve-conflicts` through its `operation` input. Instructions are required for `change`, optional for `fix-ci`, and left blank for `resolve-conflicts`. All three operations share a concurrency group per normalized PR number.

The Phase, Description and Actions columns also feed the Agentic tab of `vb-manager-next-mobile` at build time. Keep the `### Agentic` heading, the `Phase | Description | Actions` column order, each Description as `` `name` — summary `` and each Actions cell as one markdown link (or `N/A` to omit the row), otherwise that build fails; see its [home tabs doc](./projects/nx-workspace/apps/vb-manager-next-mobile/docs/features/home.md).

Entry points in one row share a task contract and differ only where [entry-point parity](./docs/agent-support.md#entry-point-parity) documents it.

_Command notation: `/name` for Claude; `$name` for Codex._
