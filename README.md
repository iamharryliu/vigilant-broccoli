### Agentic

| Phase    | Name                                  | Description                                                                        | Actions                                                                                            | Docker Sandbox                                                                 | Local                                                                  |
| -------- | ------------------------------------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| Plan     | `agentic-pr-create-rnd`               | Research a question and write an R&D note.                                         | [manual-agentic-pr-create-rnd](./.github/workflows/manual-agentic-pr-create-rnd.yml)               | `pnpm agentic-pr-create-rnd "<question>"`                                      | `/agentic-pr-create-rnd <question>`                                    |
| Plan     | `agentic-pr-create-todo`              | Refine the initial request using repo research, then add an actionable TODO entry. | N/A                                                                                                | `pnpm agentic-pr-create-todo "<description>"`                                  | `/agentic-pr-create-todo <description>`                                |
| Develop  | `agentic-pr-create`                   | Implement a TODO item or a free-text task.                                         | [manual-agentic-pr-create](./.github/workflows/manual-agentic-pr-create.yml)                       | `pnpm agentic-pr-create <id...>` or `pnpm agentic-pr-create --prompt "<task>"` | `/agentic-pr-create <id...>` or `/agentic-pr-create --prompt "<task>"` |
| Develop  | `agentic-pr-update`                   | Apply a requested change to an existing PR.                                        | [manual-agentic-pr-update](./.github/workflows/manual-agentic-pr-update.yml)                       | `pnpm agentic-pr-update <pr> "<instruction>"`                                  | `/agentic-pr-update <pr> <instruction>`                                |
| Develop  | `agentic-pr-update-fix-ci`            | Fix a PR's failing CI from its check logs.                                         | [manual-agentic-pr-update](./.github/workflows/manual-agentic-pr-update.yml) (`fix-ci`)            | `pnpm agentic-pr-update-fix-ci <pr> ["<instruction>"]`                         | `/agentic-pr-update-fix-ci <pr> [instruction]`                         |
| Develop  | `agentic-pr-update-resolve-conflicts` | Merge origin/main into a PR branch and resolve conflicts.                          | [manual-agentic-pr-update](./.github/workflows/manual-agentic-pr-update.yml) (`resolve-conflicts`) | `pnpm agentic-pr-update-resolve-conflicts <pr>`                                | `/agentic-pr-update-resolve-conflicts <pr>`                            |
| Test     | `agentic-pr-create-smoke`             | Exercise the agentic pipeline with a timestamp update.                             | [manual-agentic-pr-create-smoke](./.github/workflows/manual-agentic-pr-create-smoke.yml)           | N/A                                                                            | N/A                                                                    |
| Maintain | `agentic-pr-create-prune`             | Remove dead code, unused dependencies and stale docs that nothing references.      | [cron-agentic-pr-create-prune](./.github/workflows/cron-agentic-pr-create-prune.yml)               | `pnpm agentic-pr-create-prune`                                                 | `/agentic-pr-create-prune`                                             |
| Maintain | `agentic-pr-create-todo-audit`        | Verify existing TODO rows, remove resolved entries, and correct stale references.  | [cron-agentic-pr-create-todo-audit](./.github/workflows/cron-agentic-pr-create-todo-audit.yml)     | `pnpm agentic-pr-create-todo-audit`                                            | `/agentic-pr-create-todo-audit`                                        |

The update workflow selects `change`, `fix-ci`, or `resolve-conflicts` through its `operation` input. Instructions are required for `change`, optional for `fix-ci`, and left blank for `resolve-conflicts`. All three operations share a concurrency group per normalized PR number.

_Command notation: `/name` for Claude; `$name` for Codex._
