# Chat

Private live chat room for the owner, gated by Vercel Authentication.

## Table of Contents

- [Stack](#stack)
- [Environment](#environment)

## Stack

- Language - TypeScript
- Framework - Next.js
- Build Tool - Next.js
- External libs
  - Socket.IO
  - Tailwind CSS
- Internal libs
  - `common-js`
  - `common-node`
  - `react-lib`
  - `react-lib-higher-level`
- Cloud services
  - Socket Server - called over HTTP and Socket.IO
  - Vercel - Vercel Authentication
