# Component Library

Browsable sandbox of the shared React libs, with one sidebar group per lib (`react-lib`, `react-lib-higher-level`, `react-lib-calendar`, `react-lib-auth`, `react-lib-media`, `react-music-lib`, `react-utility`), including a Weather Display entry seeded from live Open-Meteo weather, with controls for temperature, humidity, wind, condition, day/night, units and preparation badges.
