# Weather Page

Current weather for the browser's location: city, temperature, condition, today's high and low, feels-like, humidity, wind and precipitation, a swipeable forecast of every day the provider returns (up to 16; click the weather tile), the clock, sun times and moon phase, plus what-to-wear-or-bring badges (see [Preparation Badges](./preparation-badges/README.md)). The UI is the shared `WeatherClockCardUtilityContent` from `react-utility` (see [Dashboard Info Card](../../../../../libs/@vigilant-broccoli/react-utility/docs/features/weather-clock-card.md)); this app only supplies the `/api/weather` and `/api/preparation` data fetching.
