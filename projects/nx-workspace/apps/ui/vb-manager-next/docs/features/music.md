# Music

## Overview

- `/music` page (sidebar entry, `SIDEBAR_ROUTE.MUSIC`) hosts the Metronome from `@vigilant-broccoli/react-music-lib` and the DJ Music utility (`src/app/components/utilities/dj-music.utility.tsx`) each in its own card, side by side (DJ Music left, Metronome right) from the `md` breakpoint up and stacked below it
- Both used to live in the Utilities modal; they were moved here so music tools sit together
