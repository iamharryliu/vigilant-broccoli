# VibeCheck Lite

Current weather for the browser's location: city, temperature, condition, and today's high and low.

## Table of Contents

- [Deployment URLs](#deployment-urls)
- [Stack](#stack)

## Deployment URLs

## Stack

- Language - TypeScript
- Framework - Next.js (React)
- Build Tool - Next.js
- External libs
  - Tailwind CSS
- Internal libs
  - `common-browser`
  - `common-js`
  - `common-node`
  - `react-lib`
- Cloud services
  - Open-Meteo (weather)
  - Nominatim / OpenStreetMap (reverse geocoding)
  - Vercel
