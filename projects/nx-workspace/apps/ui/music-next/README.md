# Music Next

DJ music downloads and Rekordbox launcher, metronome and Spotify playlist relationship graph.

## Stack

- Language - TypeScript
- Framework - Next.js
- Build Tool - Next.js
- External libs

  - Tailwind CSS
- Internal libs
  - `@harry/private`
  - `common-js`
  - `common-node`
  - `docs-explorer`
  - `infrastructure`
  - `react-lib`
  - `react-lib-auth`
  - `react-music-lib`
- Cloud services
  - Spotify Web API
  - Supabase
