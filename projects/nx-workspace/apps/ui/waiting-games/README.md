# Waiting Games

Hands-free games to watch while queuing or travelling, served at waiting.harryliu.dev.

## Table of Contents

- [Deployment URLs](#deployment-urls)
- [Stack](#stack)

## Deployment URLs

- Staging: `staging-waiting-games.pages.dev`
- Production: [waiting.harryliu.dev](https://waiting.harryliu.dev) (Cloudflare Pages `production-waiting-games`)

## Stack

- Language - TypeScript
- Framework - React
- Build Tool - Vite
- External libs
  - Tailwind CSS
  - Radix UI (via `react-lib` `Dialog`)
- Internal libs
  - `react-lib`
- Cloud services
  - Cloudflare Pages
