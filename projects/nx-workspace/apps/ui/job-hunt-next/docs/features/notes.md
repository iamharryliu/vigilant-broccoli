# Notes

- Notes is a single free-text notepad opened from the sidebar.
- Edits save automatically after a short pause, and on leaving the page, to the `notes` table of the local SQLite database.
- An eye button in the corner switches the textarea to a rendered markdown preview (docs-explorer's `MarkdownViewer`, the same viewer Hearth's whiteboard uses) and a pencil button switches back; the preview is not saved separately.
- The demo build is read-only and starts empty.
