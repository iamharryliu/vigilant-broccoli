# Skills

- Skills is one sidebar page under Career profile with an icon tab strip and no page header: My skills (`/skills`) and Graph (`/skills/graph`), each its own URL. Glossary (`/skills/glossary`) is a top-level sidebar item beside Settings, so the sidebar search finds it. My skills and Graph are built from the captured postings scored against the career experience file's Skills table (`use-posting-matches.ts`); Glossary needs no postings.
- My skills shows the predefined skills by group (`skill-graph.utils.ts` assigns each vocabulary term to a group; a missing term lands in Other) with how many the career file covers, a progress bar per group and chips that are green when owned and orange when a gap, each with its posting count. A summary card gives skills owned, gaps, postings captured and the top three gaps, and Gaps only hides owned skills. Groups sort by demand (postings naming any of their skills), skills within a group by postings. Career-file skills that no predefined term covers are listed under Other so nothing owned is hidden. Clicking a chip opens the postings dialog.
- Graph draws the groups and skills with docs-explorer's `GraphView`: a hub node per group, every skill linked to its hub, and node size from link degree. Dashed links join skills named together in at least a chosen number of postings; they are off by default. The gear holds that switch and slider plus docs-explorer's color scheme, glow and force settings (`useGraphSettings` with the `job-hunt-skills` prefix). Clicking a skill opens its postings.
- Owned skills outside the vocabulary and skills accepted from suggestions are not in the graph.
- Glossary lists every vocabulary term alphabetically with a one-line description from `skill-descriptions.utils.ts`; a term without an entry shows an empty description, so add one when adding a vocabulary term.
