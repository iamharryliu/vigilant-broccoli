# Settings

## Preferences

- Settings is available from the sidebar and stores the selected theme and language in this browser.
- Each label sits inline beside its select.
- Theme can follow the system appearance or stay light or dark, picked with react-lib's `ThemePreferenceControl` (a System/Light/Dark segmented control); System clears the saved override so OS changes apply live.
- Language can be English or Swedish. The choice updates app copy and the document language.
