# Job Hunt

Tailors a resume and cover letter to each job posting with Claude Code, from career files the user owns.

## Table of Contents

- [Stack](#stack)
- [Environment](#environment)

## Stack

- Language - TypeScript
- Framework - Next.js
- Build Tool - Next.js
- External libs
  - Claude Code
  - esbuild
  - Lucide
  - Playwright
  - React Markdown
  - remark-gfm
  - Tailwind CSS
- Internal libs
  - `common-js`
  - `react-lib`
  - `react-lib-higher-level`
  - `resume`
- Cloud services
  - Anthropic
