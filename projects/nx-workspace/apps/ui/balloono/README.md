# Balloono

Bomberman-style water balloon battles in the browser: online rooms with friends, or matches against CPU opponents at three difficulty levels.

- [Stack](#stack)

## Stack

- Language - TypeScript
- Framework - Next.js
- Build Tool - Next.js
- External libs
  - Lucide
  - Supabase JS
  - Tailwind CSS
- Internal libs
  - `react-lib`
- Cloud services
  - Supabase
